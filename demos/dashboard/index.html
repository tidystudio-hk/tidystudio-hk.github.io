What the real deliverable looks like

This page is a mock rendered as a web page. The actual dashboard is built inside your own Google Sheet.

  • A dashboard tab with the key numbers, charts and tables shown here, built from your columns
  • Formulas that update the dashboard when you add new rows to your data tab
  • Drop-down filters for period, channel or whatever you track
  • A tidy data tab with consistent dates, currencies and categories
  • A short note explaining where each number comes from
  • Shareable and printable like any other Google Sheet
